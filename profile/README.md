## 👋 About us

MARZ is a small team of developers working between **Italy 🇮🇹 and Tunisia 🇹🇳**.
We turn everyday problems into simple, fast and secure software: built for phones first,
available in **4 languages**, and easy for non-technical owners to run on their own.

## 🔐 How we build

- **Mobile first:** most of our users are on a phone.
- **4 languages:** 🇫🇷 French · 🇹🇳 Arabic · 🇮🇹 Italian · 🇬🇧 English, with real right-to-left layouts for Arabic.
- **Secure from day one:** signed sessions, rate limits, strict Content-Security-Policy, no secrets in code.
- **Owners stay in control:** every project ships with an admin panel, so no developer is needed for daily changes.
